# 扩张环面的局部能量：先付清远压力

2026-09-07。PRIVATE_CORE。MI-P的第一项证明草稿，内部探索记录，尚未科学发布冻结。范围是局部能量及压力的一致界，不是正则性或全空间mild坏数据的认证。FULL GOAL OPEN / NOT CLAY。

## 1. 要证明的量及尺度

令 \(\mathbb T_L^3=(\mathbb R/L\mathbb Z)^3\)，取无外力、\(\nu=1\) 的全局suitable Leray解 \(v,p\)，初值平均零。压力取周期零均值逆Laplacian给出的规范。沿用MI第3节的周期弱解、初始迹和局部能量不等式接口。以下每个固定L上解有有限全域能量，但结论的常数不能依赖其大小或L。

假设 \(L\ge64R\)，定义
\[
 e_R(s)=\sup_{x\in\mathbb T_L^3}\int_{B_R(x)}|v(y,s)|^2dy,\quad
 A_R(t)=\mathop{\rm ess\,sup}_{0<s<t}e_R(s),\quad
 D_R(t)=\sup_x\int_0^t\int_{B_R(x)}|\nabla v|^2.
 \tag{MP.1}
\]
球按周期距离理解，此处所有固定倍数的小球均可提升到欧氏局部坐标。记 \(e_0=\sup_x\int_{B_R(x)}|v_0|^2\)、\(m=e_0/R\)。目标：存在绝对常数 \(c,C>0\)，令
\[
 \lambda(m)=c(1+m)^{-2}\le1,
 \qquad A_R(t)+D_R(t)\le C e_0\quad(0<t\le\lambda(m)R^2),
 \tag{MP.2}
\]
并控制每个球上的压力减去合法时间函数后的 \(L^{3/2}\) 积分。\(e_0=0\) 时初值及解为零，以下考虑正值。

若 \(\|v_0\|_{\dot H^{1/2}(\mathbb T_L^3)}\le M\)，固定周期Sobolev经缩放给 \(\|v_0\|_{L^3(\mathbb T_L^3)}\le C M\)，常数与L无关；Hölder于是给 \(e_0\le C M^2R\)。这里采用未除以胞体积的范数，保持临界缩放不变。

## 2. 周期压力核：零模与副本没有消失

令 \(-\Delta G_L=\delta_0-L^{-3}\)、\(\int_{\mathbb T_L^3}G_L=0\)。从单位环面构造即可得到所需的一致常数：在单位胞内取截断 \(\chi_0\Gamma\)，其中 \(\Gamma(x)=(4\pi|x|)^{-1}\)，\(\chi_0=1\) 于 \(B_{1/4}\)、支集在 \(B_{1/3}\)。写 \(-\Delta(\chi_0\Gamma)=\delta_0+g\)，其中g光滑且 \(\int g=-1\)。因此 \(-1-g\) 光滑且均值为零，可用非零Fourier模求解 \(-\Delta H=-1-g\)，H为光滑周期函数。调节常数得到 \(G_1=\chi_0\Gamma+H\)。H的各阶导数在单位环面有界。

缩放 \(G_L(z)=L^{-1}G_1(z/L)\)。因此在 \(|z|<L/4\) 有 \(G_L=\Gamma+H_L\)，\(D^kH_L=O(L^{-1-k})\)。令 \(K_{L,ij}=\partial_i\partial_jG_L\)，作为分布定义；则
\[
 K_{L,ij}=\partial_i\partial_j\Gamma+O(L^{-3})\quad (|z|<L/4),\qquad
 |\nabla K_{L,ij}(z)|\le C d_L(z,0)^{-4}\quad(z\ne0).
 \tag{MP.3}
\]
第二式在单位环面奇点附近由欧氏核得到，在远离奇点的紧集上由光滑性得到，再缩放。没有逐项使用不绝对收敛的 \(|z|^{-3}\) 周期副本级数。近场 \(\partial_i\partial_j\Gamma\) 保留其分布接触项，不能只写成离开零点的主值核而漏掉局部项。常数源 \(-L^{-3}\) 已包含在H中。

固定中心 \(x_0\)，取 \(0\le\chi\le1\)，在 \(B_{4R}(x_0)\) 为1、支集在 \(B_{8R}(x_0)\)。压力完整分解
\[
 p=p_{\rm near}+p_{\rm far},\quad
 p_{\rm near}=K_{L,ij}*(\chi v_i v_j),\quad
 p_{\rm far}=K_{L,ij}*((1-\chi)v_i v_j),\quad
 c_{x_0,R}(s)=p_{\rm far}(x_0,s).
 \tag{MP.4}
\]
求和及卷积均在整个周期胞，近场分布卷积合法；远场在该中心无核奇性。对 \(x\in B_{2R}(x_0)\)，由MP.3沿x方向积分，再按 \(d_L(y,x_0)\sim2^kR\) 分壳。每壳可用 \(C2^{3k}\) 个半径R的球覆盖，故
\[
 |p_{\rm far}(x,s)-c_{x_0,R}(s)|
 \le C\sum_{k\ge2}R(2^kR)^{-4}2^{3k}e_R(s)
 \le C e_R(s)R^{-3}.
 \tag{MP.5}
\]
和式在胞直径处终止，上界则可延伸到无穷。周期距离在割迹处不必可微：被微分的是光滑周期Green核，沿长度不超过2R的局部路径，到源的距离始终不小于原距离的一半。这样既保留最远胞区域，也没有留下 \(\log(L/R)\) 费用。

近场用MP.3中的欧氏双Riesz算子及其光滑余核。欧氏Calderón–Zygmund给 \(L^{3/2}\) 有界；余核振幅至多 \(C L^{-3}\int_{B_{8R}}|v|^2\le C e_R/R^3\)。因此
\[
 \int_{B_{2R}(x_0)}|p-c_{x_0,R}(s)|^{3/2}
 \le C\int_{B_{8R}(x_0)}|v|^3+C R^{-3/2}e_R(s)^{3/2}.
 \tag{MP.6}
\]
规范函数可以依赖中心和R，但只依赖时间而不依赖x；故不改变方程或局部能量中的压力通量积分。没有声称未减规范的压力有同样的一致界。

## 3. 局部能量bootstrap

对等于1于 \(B_R\)、支集在 \(B_{2R}\)、梯度和Laplacian分别为 \(O(R^{-1}),O(R^{-2})\) 的非负空间截断，使用含初始项的局部能量不等式。压力规范项的积分为零，因为 \(\operatorname{div}v=0\)。MP.6、空间Hölder及Young给
\[
 A_R(t)+D_R(t)\le C e_0+C R^{-2}\int_0^t e_R(s)ds
 +C R^{-1}\sup_x\int_0^t\int_{B_{8R}(x)}|v|^3
 +C R^{-5/2}\int_0^t e_R(s)^{3/2}ds.
 \tag{MP.7}
\]
例如远压力通量的空间积分至多 \(C e_R^{3/2}R^{-3/2}\)，再乘截断梯度 \(R^{-1}\) 就是末项。两个sup分别取在空间局部能量和局部耗散上，不能以 \(\int\sup_x\int|\nabla v|^2\) 替换后者。

局部Gagliardo–Nirenberg、有限球覆盖和时间Hölder给
\[
 \sup_x\int_0^t\int_{B_{8R}(x)}|v|^3
 \le C t^{1/4} A_R(t)^{3/4}D_R(t)^{3/4}
       +C t R^{-3/2}A_R(t)^{3/2}.
 \tag{MP.8}
\]
在各固定中心先作时间积分，再取sup，就能用D_R控制有限覆盖球的耗散。局部插值中的低频 \(R^{-3/2}A_R^{3/2}\) 项已保留，不要求球内平均零。

写 \(F=(A_R+D_R)/R\)、\(\tau=t/R^2\)，得到
\[
 F(t)\le C m+C\tau F(t)+C(\tau^{1/4}+\tau)F(t)^{3/2}.
 \tag{MP.9}
\]
只写这个多项式不等式不足以自动选择小分支。为严密处理弱解时间正则性，定义H(t)为MP.7右侧（固定足够大的绝对常数，其初始项系数记为 \(C_0\)）。对每个固定有限L，\(e_R\) 受有限全域能量控制，\(|v|^3\) 在有限时段全域可积；空间sup的时间积分共享该全域积分的绝对连续模。因此H连续、非减、\(H(0)=C_0 e_0\)，且 \(A_R+D_R\le H\)。将MP.8及这个上界代回H的定义，\(h=H/R\) 满足 \(h\le C_0m+C_1\tau h+C_2(\tau^{1/4}+\tau)h^{3/2}\)，其中各常数已固定。

取门槛 \(h=2C_0 m\)。若 \(\tau\le c(1+m)^{-2}\)，选足够小的绝对c，可使 \(C_1\tau h+C_2(\tau^{1/4}+\tau)h^{3/2}<C_0 m\)。H连续且从 \(C_0 e_0\) 起步，不能首次到达该门槛。故MP.2成立。此处全域有限能量仅用于每项H的连续性，不进入最终常数，也没有用于跨n的一致界。

由MP.6、MP.8和MP.2还得到
\[
 \int_0^{\lambda(m)R^2}\int_{B_{2R}(x_0)}|p-c_{x_0,R}(s)|^{3/2}
 \le C(m) R^2.
 \tag{MP.10}
\]
该证明建立在列明的标准周期suitable解接口、欧氏CZ及局部Sobolev插值上；周期核、副本、远场费用及bootstrap则已在本稿展开。未宣称这一类局部能量估计具有新颖性。

## 4. 回到MI的零年龄序列：能做什么，仍缺什么

对MI.6序列 \(L_n=2\pi/r_n\to\infty\)，初始临界范数至多M，所以在每个固定R及足够大n上 \(m\le C M^2\)。取一个足够大的固定 \(R_*\)，使 \(c(1+C M^2)^{-2}R_*^2>2\)。MP.2与MP.10就在 \(B_{R_*}\times(0,2)\) 提供一致能量、耗散与规范后压力界。对任意其他固定观察球，可再取更大的固定R；并不要求同一个有限n容纳全部R，也不交换这两个量词。

这付清的是MI-P的局部有界性部分，尚不是MI-P全部。下一步须写出：扩张周期初值如何在全空间 \(\dot H^{1/2}\) 中获得正确极限与局部强L2初迹；不同球的压力规范如何统一；强局部速度紧性与压力谐和部分如何保住 \((0,1)\) 奇点；最后所得suitable极限是否属于能够与该初值mild解比较的Leray类别。不能从“局部suitable且初值临界”一句话直接跳到全空间mild寿命不超过1。

全空间相应思路参见[Rusin–Šverák Lemma 4.1](https://arxiv.org/html/0911.0500v1)，该引理所引用的Lemarié-Rieusset专著证明未在本轮逐项读取；本稿没有以改写域名代替周期证明。另核读[Bradshaw–Tsai，arXiv:1907.00256v1，Definition 1.1与Lemma 2.1–2.2及相关证明](https://arxiv.org/html/1907.00256v1)：全空间局部能量估计已有相同量级的时间长度与初始局部能量控制，并将完整近/远压力表示列为解类别条件。该来源早已出现在本项目R074H来源记录，本轮是针对具体引理的重读，不是新来源发现；也没有认证该文其余全部证明。本稿直接展开周期核与bootstrap，未把周期提升属于该文解类别当作未经证明的捷径。
