# FA 首代输出与下一门输入：实际核对笔记

2026-09-07。PRIVATE_CORE。未冻结的返回接口审计；以下不是新候选，也不重新计算 FA 已证的一次激活。

本轮根代理全文读 research/clay_b_frequency_activation_20260907.md，并读 public/notes/r0-10.html §7、r0-11.html §3、§6–7 的实际命题/证明。R0.10 原文给特定等长门的一维像；R0.11 §3 引理1已明确给出一般等长门的像包含于 span(p×q)。这不是本次新提出的推广。它们已经说明输出能量与可供下一门使用的输入状态不同。这里仅将这一界面明确对接到 FA 的四叶种子。

FA 使用 p=(3/2)e1、q=(3/2)e2，中心极化 A=e2、B=e3。统一使用 FA 的正号非线性 Γ=χ(D)P div(F⊗F)。在 κ=σp+τq，σ,τ∈{±1} 的中心主项，有

P_κ i[((τq)·A)B+((σp)·B)A]=(3τ/2)i e3。

因此四个输出中心是 ±(p+q)、±(p−q)，两个代表元等长且正交，但所有输出中心主极化仍共用法向 e3。共同正交变换、倍率与空间平移分别改变坐标、幅度和相位，不能把一条共同极化线变成 FA 下次所需的两条独立极化线。一条输入极化位于中心波矢平面内，另一条为法向；这是真实输入的结构差别。

R0.11 §6 命题3另有差频核为零的前提，而当前FA在p−q的中心主项非零。因此那条一维反向闭合定理不能直接用于本例；可直接使用的是§3等长门像的引理。§7的具体反向缺陷常数也不能从另一个网络搬到FA。

若只保留这些中心及共同法向的主项，对任意两个第一代中心 r,s，r·e3=s·e3=0，因而

P_(r+s)i[(s·e3)e3+(r·e3)e3]=0

（r+s=0 的零模也为零）。这只是中心主项的二次退化，不能用来宣布固定包宽的 B(G_N,G_N) 恒零。也不能由此删去原种子混合项。

包宽误差需要另行记录。FA 的 ψ 非负且偶，卷积核在四个非零目标邻域光滑。对充分小包宽 δ，每个目标邻域只有相应两个有序区域贡献，Leray核与频率因子距中心值为 O(δ)。因此中心主项为常数法向乘 ψ_δ*ψ_δ，偏离它的向量受 Cδ(ψ_δ*ψ_δ) 控制。这里卷积非负，允许逐点绝对值上界；并非用相位抵消推测误差。记 Jδ=ψ_δ*ψ_δ，Jδ(0)>0且四叶不交。若Cδ<3/2，则 Euclidean 初始源的总Fourier L2范数至少为 2(3/2−Cδ)||Jδ||2/(2π)^3，法向外与总量之比至多 Cδ/(3/2−Cδ)。这支付了非零分母，故比例为O(δ)，而绝对主量仍随δ^(3/2)缩小。没有数值化常数或δ阈值；不能将比例不加误差直接迁移到周期G_N或正时间原解，也不据此排除固定包宽的所有返回状态。

实际解还含 FA.14 的 O(s²) 时间误差，主目标为 −sG_N；这里时间改记s，与上面的中心正负号τ区分。FA.14确能传递目标场的L2结构信息：若C0s<||G_N||2，则实际目标法向外比例至多 (||P⊥G_N||2+C0s)/(||G_N||2−C0s)。目标支撑在固定尺度的紧频带还允许把目标L2误差提升到固定阶目标带Sobolev误差。因此不能说FA没有状态信息或没有完整无限维余项。尚缺的是下一门完整返回模板、接收时间、按真实供给来源分拆的原种子混合项与其它模式，以及下一阶段的完整演化合同。用目标主项的O(δ)结构作第二次演化须同时控制δ、周期化与s的相对误差；FA没有提供该返回结论。FA.13的常数对N一致，不意味着它们在δ→0时一致。FA的Q_N是光滑乘子，不是幂等正交投影，不能不加证明地用它定义正交的各代能量。

当前审计结论为：几何中心可以构成下一对等长正交方向；二维输入极化与完整动态状态尚未返回。中心法向退化是旧等长门障碍的具体实例，不作为新定理或新的冻结包。有限宽变形、混合供给和相位可能改变后续，但现有原文没有认证一个完整返回状态；未把这些未付条件称作候选。还须对照独立推导和实际输入字节后才完成本次接口审计。
