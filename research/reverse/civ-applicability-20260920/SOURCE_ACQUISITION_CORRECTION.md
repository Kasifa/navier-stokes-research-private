# 来源获取记录的范围纠正

2026-09-20，PRIVATE_CORE。保留所有已获取字节及被审稿引用的旧 manifest，不覆盖它们来掩盖来源获取历史。

`sources/manifest.json` 的 `scope` 和逐来源完整性字段已指出 20803 HTML 响应截断，但 `extraction` 中的“full article … proofs, appendices, references retained”措辞过宽。正确含义仅为：抽取器保留**实际收到的 article 内容**，并将其中的 MathML 换为原 alttext；它没有断言响应包括完整文章。20803 HTML 在 §4/(4.10b) 中断，没有完整 §4 后段、§5、Appendix A 或参考文献，不能作为这些部分的来源。获取之初未断言 HTML 闭合，是抽取器的已知限制。

后续取得的官方固定 v1 PDF 为主要完整来源：20803 为34页，20762为24页，均保存原字节及逐页标记的 pypdf 抽取。20803 的所需缺失章节由来源作者读 PDF 补足。20762 的 HTML 有正文与文档闭合、完整参考文献，并由来源作者将关键数学页与 PDF 对照；这不等于每页视觉审查。

保存源文件、哈希相符、正文闭合、实际阅读证明及重证外部引用是不同证据。两份 PAPER_*_AUDIT 的具体阅读范围才是证明审读记录；本文件不扩大其范围。来源页面 PNG 是原文阅读证据，科研图数量仍为0。

20762审核引用 `sources/manifest.json` 的 e8834f3f… 哈希，是作者当时读到的初始版本，现原样保存为 `sources/manifest-initial-html.json`；当前补齐PDF后的清单为20271c5d…，20803审核已引用这个新版本。两份审核记录的是不同时点实际读取，不能将早期记录误说成核过后补PDF清单。八个源对象的字节长度和SHA已逐件与当前清单核同；数学阅读范围仍各按审核所载。
