## 2. 有理运算、平方自由分解与证据

所有科学多项式为升幂 Fraction 元组；零的次数为 \(-1\)，尾零被规范去除。加、减、卷积乘法、导数和 Horner 求值均保留精确有理数。除法逐次消去最高项，检查
\[
a=qb+r,\qquad r=0\ \text{或}\ \deg r<\deg b;
\]
要求整除的调用另核 \(r=0\)。源码中的常数除以 Fraction 仍是有理运算；浮点计时不参与科学零判或根选择。

positive_primitive 先取分母的最小公倍数，再除整系数内容的正 gcd，返回 \(c a\) 和明确的 \(c>0\)，不改变任一非零系数符号。Euclidean gcd 证书保存两个初始正倍数、每步商、余式的正倍数和最终首一倍数；末次首一倍数可以为负，但被明确区分为 gcd 规范，不混入 Sturm 链的正缩放。每个输入还被核为最终 gcd 的精确倍数。

square_free 将非零非常数 \(P\) 首一化为 \(F\)，先取 \(g=\gcd(F,F')\)、\(Q=F/g\)，再按
\[
y=\gcd(w,g),\quad f_i=w/y,\quad
(w,g)\leftarrow(y,g/y)
\]
依次提取重数 \(i\) 的非平凡因子。循环结束要求残留 \(g=1\)，并逐项核
\[
F=\prod_i f_i^i,\qquad Q=\prod_i f_i,
\]
各 \(f_i\) 平方自由、两两互素，且 \(Q\) 平方自由。原 \(P\) 的首项系数也参与重构检查。因此没有把平方自由化当作丢弃重数，或把可约因子误称不可约因子。多项式整数 ID、gcd 记录 ID 和因子记录相互引用，可由输出原有理系数逐条复核。

零多项式与非零常数 \(P\) 在进入此算法前分别走合同的退化未认证与本图无候选分支，不强行求根，也不将 \(P\equiv0\) 解释为整个数据族都不可能。

## 3. Sturm 链、半开区间、根序与 128 次路径

Sturm 的首项为 \(q\)，第二项为 \(q'\) 的正 primitive 倍数；其后每项满足
\[
S_{j+1}=-c_j\,\operatorname{rem}(S_{j-1},S_j),\qquad c_j>0.
\]
每步商、\(c_j\) 与下一项 ID 均保存，终止除法另记零余式及商，并要求末项为非零常数。结合保存的完整链序，可以核全部相邻除法。代码未把负首项的链项强行首一化。

variation 删去端点零值后计符号变化，count 取 \(V(a)-V(b)\)，固定计数 \((a,b]\)。根界取
\[
B=2+\left\lceil\max_{j<\deg Q}|Q_j/Q_{\deg Q}|\right\rceil,
\]
严格覆盖通常的 Cauchy 根界，且代码另核两端不是根。根数为零的区间被记录为空；多根区间分成 \((a,m]\)、\((m,b]\)，检查两子计数之和。中点根只属于左区间，右端为根的唯一根区间另存精确有理点。

isolate 左侧先行，最后检查孤立根数量等于全局 Sturm 根数，且相邻区间按序不交叠；所以所得顺序足以指定首根，没有使用浮点近似排序。各平方自由因子在每个唯一根区间单独计数，并要求恰有一个因子含此根，恢复原 \(P\) 的根重数。实根重数总和只要求不超过 \(\deg P\)，正确保留可能的非实根。

split 在父深度达到 128 时停止；初始全局区间深度为零，每次分裂加一。选定根的后续细化沿 current_node 继续而不重置，因子零判也不另起隔离树。故所有祖先隔离和该根后续二分确实共用同一路径预算；深度 128 尚有多根或非零区间仍未分离时只能未认证。

gcd 缓存和根零判缓存不会把一个根的结论用于另一个根：零判键包含 root index，原测试记录其实际 root_node。选定根细化后沿已记录子区间继续，旧唯一根区间中的结论对该同一根仍有效，无需改写旧证据为新端点。

## 4. 指定根零判、原始 \(M\) 与完整六目标

每次 zero_test 实际构造 \(d=\gcd(Q,f)\)，在该根当前唯一根区间计 \(d\) 的根数，要求为零或一，以一恰判 \(f(\alpha)=0\)。若检测到精确右端点根，还直接有理求值交叉核对。常数 gcd 和 \(f=0\) 均被已有 gcd/Sturm 分支覆盖。没有把 \(Q\) 当数域，也没有代数求逆或“非零余式即指定根非零”的错误捷径。

read_stored_coefficients 核固定 schema、阶段 A 状态和 exact_checks，解析原始 \(C,Z,M,P\)，并检查 \(M\) 正是完整 \(Z\) 前两行、\(P=\det M\)、原三分量横向性及次数界。六个目标按旋转和正负顺序锁定；保存的 \(C,M13,M31,Z,\text{full_four_leaf}\) 各分量均解析，逐项核旋转/负频号、横向性、\(M13+M31=Z\) 与 \(C+Z=\text{full_four_leaf}\)。负频记录的实系数反号与整体物理相位 \(+i\) 相容。

这些输入内部恒等式不是重新生成五树或重新证明阶段 A 的物理系数。所有原始 Fourier/Leray 树系数的真实性仍由阶段 A 及之后独立核验承担；本源码没有以此为由重跑阶段 A。

每个根先核 \(P(\alpha)=0\)，再按原始行序测试 \(M\) 的全部元素。行值全部为零取秩零，否则由已付 \(\det M=0\) 取秩一。秩一直接使用原行多项式
\[
(v,w)=(-s,r),
\]
无清分母、行幅度重缩放或首一化。秩零先测试完整 \(C\) 第一列，非零则固定 \((1,0)\)，否则固定第二列对应 \((0,1)\)；若两列均零，最终 complete C 判定将该根列为不合格。

代码随后构造同一原规范的 \(V,C,Z\)，精确核 \((v,w)\ne0\)、\(V\ne0\)、全部三分量 \(Z=0\)，并再次对全部六目标的完整 \(C,Z\) 作零判。各目标 \(Z\) 必须为零，\(C\) 整向量非零身份须与主目标相同；\(C\) 每分量的零/非零和测试 ID 均保存。

认证根上若 \(P\) 零判矛盾、规范向量为零、完整 \(Z\) 非零或旋转/共轭状态不一致，require 抛出证书不一致并退出本阶段。没有把这种根跳过后继续选择的分支。秩二矛盾停止规则虽理论上不应触发，源码也没有把它改作普通供给失败。
