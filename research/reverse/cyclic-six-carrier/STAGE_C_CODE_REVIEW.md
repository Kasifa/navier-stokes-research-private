## 2. 独立有限树及 A 比较覆盖

vertex 保留有序导数“左幅度点右频率”乘完整右向量，并用
\[
P_kY=-k\times(k\times Y)/|k|^2
\]
投影。双叉积的负号正确；每个输入、每个输出均核横向性。零输出时先要求有序导数为零，再返回零向量，不作零分母除法。每门的 \(-i\) 被一致剥离，三个顶点给四叶公共物理相位 \((-i)^3=+i\)；同时翻转四片叶频率给剥相位根场反号，恢复相位后为真实共轭。

五个显式括号形穷尽四叶平面有序二叉树。每形遍历四个不同标签的全部 24 个排列；每个内部 m 叶子树除以 \(m-1\)，所以平衡形权重为 \(1/3\)，其余四个链形为 \(1/6\)。平衡形单独形成 C，根为 1+3 的两形形成 M13，根为 3+1 的两形形成 M31；Z 和完整总项另由完整向量相加。所有三个分量均保留。

## 3. 全部有理证书、gcd 与 Sturm

B 多项式用稀疏 Fraction 重新解码，核 ID 顺序、规范编码、去重和次数。160 个多项式最终都须由验证路径访问；21 条 gcd、2 条 Sturm、15 个节点、38 条零判和 2 条根记录是这份不可变成功证书的完整表长门。它们不是对任意其它 P 的预言或通用求根器的分支数量。

每条 gcd 逐步核初始正比例以及
\[
L=QR+N/c,\qquad c>0,\qquad
N=0\ \text{或}\ \deg N<\deg R,
\]
要求首尾连续并终止于非零左项和零右项，再核最终首一倍率及两输入的商恒等式。故不仅证明结果整除输入，也由 Euclidean 链证明它确为 gcd。允许最终首一倍率为负；它与 Sturm 的正倍率职责分开。

Sturm 验证实际首项、导数正倍率、每条
\[
S_{j-1}=Q_jS_j-S_{j+1}/c_j,\qquad c_j>0,
\]
的完整多项式身份及严格降次，核非零常数末项和终端除法。常数链单独处理。它检查保存倍率的正性及算式，不另生成一条 Euclidean/Sturm 链；正确计数并不要求再算 primitive 内容的规范化过程。保存的 verified 标签仅在这些验证之后核一致，未被当作数学证明输入。

Yun 记录从独立 P 的原首系数出发核 F、初始 gcd、每步商身份及重数，恢复原 P、各平方自由因子和全局 Q；因子平方自由及两两互素均由已经逐条核过的 gcd 记录支付。没有把可约 Q 当最小多项式或数域，也没有代数域求逆。

本代码针对已停定 B 的成功证书；若固定输入、表长、恒等式或成功标签不符，结果只能未认证。局部的零多项式、常数 gcd、秩零、有理点等逻辑确有处理，但此代码不是对另一份恒零/常数/无根 P 另运行分类的工具，也不声称那些分支已经被实际测试。

## 4. 全局根覆盖、同根零判及原规范

count 对实际链逐项有理求值，删零后重算端点变号数，固定用 \(V(a)-V(b)\) 计 \((a,b]\)。它同时核链所属多项式、区间和所有权，而非照抄保存的 count。中点根只归左侧，常数 gcd 的根数为零。

validate_nodes 重核原 Cauchy 界公式及端点非根。除全局首节点外，每个节点的 parent 必须为较早合法 ID，且父亲列有该子节点；每次分裂核确切中点、左右半开区间、父子计数和深度加一。节点深度不得超过 128，不能重置路径。

全局树左先遍历，空节点不可继续分裂，多根节点必须有完整子树，单根节点按原隔离资格停止。所有标记为全局隔离的节点必须恰被访问；根记录初始节点必须与该顺序完全一致，数量须同时等于全局 Sturm 根数。用于首坐标下界的后续细化不被误认作新的初始根，也不能遗漏全局分支。

每条零判先把所属根、所属单根节点及其与初始/最终节点的祖先关系核清，再从已验 \(\gcd(Q,f)\) 重算同一区间计数，核零/非零标记。引用原较早节点的缓存证书仍指同一根；精确右端点出现时另核有理点值，未出现时禁止无依据的点值字段。所有 38 条零判最终还须被实际同数据断言使用。

classify_all 的原 C/Z/M/P 先与独立有限树逐项一致。每根核因子成员与原重数、P 为零、原 M 每个元素零性，再恢复秩与规范。秩一取原首非零行 \((r,s)\) 的 \((-s,r)\)，不清分母或缩放；秩零先判完整 C 第一列，只有其为零才取第二列基向量。两列皆零会使 C 不合格，不会被当作成功。

原规范 v/w/V/C/Z 多项式均通过实际加乘与保存 ID 对比，再逐根支付 \((v,w)\ne0\)、\(V\ne0\)、完整 \(Z=0\) 和 C 每分量状态。全部六目标的原规范向量和零判再次核回。秩二、非零完整 Z 或任何引用错对象都会失败；没有跳过此根再选后根的逻辑。全根完成后才核首个合格根，且实根重数之和仅要求不超过原 P 次数，保留非实根的可能。
