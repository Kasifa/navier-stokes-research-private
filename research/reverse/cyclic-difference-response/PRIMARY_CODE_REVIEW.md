## 4. 商余、Bézout、Sturm 与首坐标规则

基本多项式操作全为整数/Fraction；零多项式正规化为单个零系数，次数记为 -1。长除每次降低最高次数，结束明确核 \(a=qb+r\)。扩展 Euclid 同步递推两个 Bézout 系数，最终首一化后再核

\[
Q=Dq_D,\qquad \widetilde f=Df_D,\qquad A_DQ+B_D\widetilde f=D.
\]

因此不仅保存 gcd 名称；输入、商余、首一 D、两个 Bézout 系数和 Euclid 轨迹均可重建。首一化的末乘子可能为负，但不拿它作 Sturm 链允许的缩放。

坐标按 1、2、3 顺序判断，到首个精确非零坐标即停；此前坐标必须已有零证书。每次使用原 \(f_j\) 对 Q 的余式求 gcd，绝不把非零余式直接当成本实嵌入非零。

\[
D=\gcd(Q,\widetilde f_j),\qquad
f_j(\alpha_*)=0\Longleftrightarrow N_D(I_0)=1.
\]

Q 在 \(I_0\) 中恰有一根，D 是其因子，故 D 的该区间根数必须为 0 或 1。超出此范围立即不一致停止。余式零时 D=Q 复用已校验旧链；非零常数对应 D=1；其它 D 的局部链直接使用 \(S_{i+1}=-\operatorname{rem}(S_{i-1},S_i)\)，缩放为正数 1，终止项须为非零常数。常数链根数为零，不要求对 D 重新全轴隔离。

端点按精确 Fraction 值取符号、删零计变号，统一计算 \(V(a)-V(b)\) 对应 \((a,b]\)。平方自由根处的右侧变号约定正确：左端根排除、右端根计入；中间链项的零值也正确删除。若原右端恰为 Q 根，另精确代入原 f 与 gcd 结论比较，不据端点近似判根。

三坐标全零时只返回完整两叶零响应资格；不启动下一阶。首非零时明确未分类后续坐标，而六行完整符号身份仍保留。任何零判中断均不会成为“零”或“无根”证书。
