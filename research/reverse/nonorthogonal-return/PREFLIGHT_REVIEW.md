## 2. 第一代空间系数、共轭与有序计数

记 \(P=|p|^2,\ Q=|q|^2,\ S=P+Q,\ c=p\cdot q\)，\(r=p+q,\ s=p-q\)。非平行性给 \(c^2<PQ\)，故 \(r,s\ne0\)，且

\[
r\times s=-2p\times q\ne0,\qquad |r|^2=S+2c,\quad |s|^2=S-2c.
\]

在双线性复点积约定下，完整有序算子是

\[
B(f,g)_k=-iP_k\sum_{a+b=k}(f_a\cdot b)g_b.
\]

到 \(r\) 的两项来自 \((p,q)\)、\((q,p)\)，到 \(s\) 的两项来自 \((p,-q)\)、\((-q,p)\)，分别为

\[
N_+=-iP_r[(U\cdot q)V+(V\cdot p)U],
\]
\[
N_-=-iP_s[-(U\cdot q)\overline V+(\overline V\cdot p)U].
\]

它们与 NH.2、NP.1–2 完全一致。负号来自第二个输入频率 \(-q\)，而不是额外的复共轭点积。第一层各自的 Leray 投影完整保留；同轴及相反轴种子配对由横向条件逐项为零。

这里 \(N_-\) 只翻转 q 种子，通常不等于 \(\overline{N_+}\)。真正翻转整个输出频率时，两个输入频率与极化一起翻转，频率负号把外层 \(-i\) 变成共轭所需的 \(+i\)，所以

\[
N_{-r}=\overline{N_+},\qquad N_{-s}=\overline{N_-}.
\]

两份稿件均没有把 \(N_+,N_-\) 当成独立自由输入，也没有假定它们非零。

对仅含这两对原种子的第一层，支撑包含于 \(\{\pm r,\pm s\}\)。利用 p、q 的线性独立性比较其系数，通向 \(2p\) 的全部配对恰是 \((r,s)\)、\((s,r)\)。因此空间系数为

\[
\mathcal K_p=-iP_{2p}[(N_+\cdot s)N_-+(N_-\cdot r)N_+].
\]

两种次序各出现一次；不能少掉反序，也不能在这个完整和外再乘二。若另有种子，该式只表示此对的贡献。主稿 NH.5–6 明确采用分账措辞，独立稿 NP.7 的等式则明确限定仅有这两对原种子，二者范围一致。未来若三个原波向量线性独立，第一层相同 r、s 处没有额外种子配对，但完整后继树仍可能有其它接收贡献。

## 3. 精确热因子与连续正交接口

两个原种子的输入热乘积都为 \(e^{-St}\)，而输出热率分别为 \(S\pm2c\)。直接积分给

\[
F_\pm(t)=\int_0^t e^{-(S\pm2c)(t-\tau)-S\tau}\,d\tau
=e^{-St}\frac{1-e^{\mp2ct}}{\pm2c}
=e^{-(S\pm c)t}\frac{\sinh(ct)}c.
\]

这核实 NH.3、NP.3–4 的三个表达，包括减号分支；没有把输出热率误设成 S。正性由积分直接给出，对 c 的两种符号都成立。因而

\[
\frac{F_+(t)}{F_-(t)}=e^{-2ct},\qquad
F_+(\tau)F_-(\tau)
=e^{-2S\tau}\frac{\sinh^2(c\tau)}{c^2}.
\]

乘积中的两个因子必须取同一个 \(\tau\)。它们仍是由同一对原种子生成的树系数，不能解释为两个独立供给时钟。

外层接收频率 \(2p\) 的热率为 \(4P\)。把两种有序项共同的乘积因子提取，得到

\[
\mathcal H_p(t)
=\int_0^t e^{-4P(t-\tau)-2S\tau}
\frac{\sinh^2(c\tau)}{c^2}\,d\tau
=e^{-4Pt}\int_0^t e^{2(P-Q)\tau}
\frac{\sinh^2(c\tau)}{c^2}\,d\tau.
\]

因此 \((w_{22})_{2p}=\mathcal H_p\mathcal K_p\) 在上述仅有两对种子的范围内严格成立；主稿的单对贡献式同样成立。所有热率、黏性及完整投影都在式内，无未估时间余项。即使 \(\mathcal H_p>0\)，空间系数仍可能为零。

NP.9 也核对一致：由

\[
\sinh^2(c\tau)=\tfrac14(e^{2c\tau}+e^{-2c\tau}-2)
\]

可得三个指数参数 \(2(P-Q+c),2(P-Q-c),2(P-Q)\) 及总分母 \(4c^2\)。定义 \(\Phi(z,t)=\int_0^t e^{z\tau}d\tau\) 后，三个参数中任何一个为零均无奇点；该相消表达式的正性仍应由前面的正积分判断。

对固定 \(0\le\tau\le T<\infty\)，

\[
\frac{\sinh(c\tau)}c=\int_0^\tau\cosh(cu)\,du
\]

在 \(c\to0\) 时一致趋于 \(\tau\)，且在任意小的固定 c 区间内一致有界。故有限积分内可严格取极限：

\[
F_\pm(t)\to te^{-St},\qquad
\mathcal H_p(t)\to
e^{-4Pt}\int_0^t \tau^2e^{2(P-Q)\tau}\,d\tau.
\]

这确实恢复旧正交热权重。该论证只把 c 作为标量公式的辅助实参数，不要求在整数格点中存在连续变形，也不固定或改变某个实际初值。标量权重为 c 的偶函数，并不使空间系数独立于波向量几何。

## 4. NP.13–14 的符号、系数与等长门

先从一般非平行实频率 \(\ell,m\) 重核。令 \(k=\ell+m\)、\(a=X\cdot m\)、\(b=Y\cdot\ell\)，且 \(X\cdot\ell=Y\cdot m=0\)。对完整有序和 \(T=aY+bX\)，有

\[
T\cdot\ell=ab,\qquad T\cdot m=ab,
\quad T\cdot(\ell-m)=0,\quad T\cdot k=2ab.
\]

由于 \(k\cdot(\ell-m)=|\ell|^2-|m|^2\)，

\[
\begin{aligned}
(-iP_kT)\cdot(\ell-m)
&=-i\left[0-\frac{2ab}{|k|^2}
(|\ell|^2-|m|^2)\right]\\
&=\frac{2iab}{|k|^2}(|\ell|^2-|m|^2).
\end{aligned}
\]

所以 NP.13 的正 \(i\) 号和因子二准确。若 \(|\ell|=|m|\)，输出同时垂直 \(k\) 与 \(\ell-m\)；两者由非平行性线性独立，故输出属于
\(\operatorname{span}_{\mathbb C}(\ell\times m)\)。这个结论对复横向极化成立，但只是像空间包含关系，不是共享原种子可达性的满射结论。

现在代入 \(\ell=r,\ m=s\)。此时

\[
\ell-m=2q,\quad k=2p,\quad |k|^2=4P,\quad
|\ell|^2-|m|^2=4c.
\]

NP.13 的左侧为 \(2\mathcal K_p\cdot q\)，右侧为
\(2ic(N_+\cdot s)(N_-\cdot r)/P\)。两边再除以二，恰得

\[
\mathcal K_p\cdot q
=\frac{ic}{P}(N_+\cdot s)(N_-\cdot r).
\]

NP.14 没有遗漏二倍因子，也没有漏掉压力项。\(c\ne0\) 只表明这个第二门不满足等长前提；即便原波向量满足 \(P=Q\)，第二门的两个输入仍不等长。两份稿件均没有由此推断右端非零、一般二维像已经达到，或共享极化多出可自由使用的参数。
