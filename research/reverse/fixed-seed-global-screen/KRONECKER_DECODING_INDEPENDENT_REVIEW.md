## 1. 固定输入、位宽与先验界

沿用唯一成本块：原档案 n=1280、同一精确投影节点、96 位 dyadic 中心、张量分量 `c̃¹*c̃²`。空间基固定 33，数位基

`B=2^240`，每位 30 bytes，输出位数 `L=33³=35937`。

输入指数为

`e(p)=(p1+8)+33(p2+8)+1089(p3+8)`。

因为两个输入坐标分别在 0..16，三个和坐标都在 0..32，指数和直接对应输出 k=p+q，且没有空间进位或混叠。最大输入指数 17968、最大输出指数 35936。物理频率由输出三个基 33 数位分别减 16 得到。

CR 的输入界是每个 Re/Im dyadic 整数标量绝对值小于 `2^109`，实虚和小于 `2^110`。每个输出最多 4912 个有序输入项，所以三个 Gauss 实卷积各系数绝对值小于 `2^233`；最终复实部、虚部即使采用粗三项界也小于 `2^235`。它们均严格小于 `B/2=2^239`。

上述界来自**原输入大小与合格求和项数**，在尚未解码、尚未看到答案时已经成立。它不从解码输出落在某个区间反推。主实现须实际核验输入满足这些已固定整数界，不得临时加宽数位、截断最高位或只取乘积低位来掩盖错误。

以下引理适用于其中任意一份整数多项式值

`z=Σ_(j=0)^(L−1) w_j B^j`，其中 `w_j∈Z, |w_j|<B/2`。

## 2. 固定宽度的 signed 导出一定容纳真值

由于 w_j 为整数，严格半基界给 `|w_j|≤B/2−1`，因此

`|z|≤(B/2−1)(B^L−1)/(B−1)<B^L/2`。

最后一个严格不等式可由 `(B/2−1)/(B−1)<1/2` 直接得到。故 z 落在 `240L` 位二进制有符号整数范围中，一次

`z.to_bytes(30*L, byteorder="little", signed=True)`

足以精确表示它。导出的长度恰为 1,078,110 bytes。这里不是把任意 z 隐式模掉高位；若有符号导出因超范围失败，必须停止。零值、负值与正值使用同一固定长度。

设这份补码字节解释为无符号整数 A，令 `ε=1` 当 z<0，否则 ε=0。补码定义给

`A=z+εB^L`。

依次取 30-byte 无符号数位 a_j，则 `A=Σ a_j B^j, 0≤a_j<B`。一次导出后，每个局部数位至多 240 bit，不再对剩余长整数作整体右移或长整数除法。

## 3. 带进位的线性扫描及不变量

取 `c_0=0`。对 j=0..L−1，定义

`t_j=a_j+c_j`，

若 `t_j<B/2`，令 `ŵ_j=t_j, c_(j+1)=0`；

否则令 `ŵ_j=t_j−B, c_(j+1)=1`。

显然每个 c_j 属于 `{0,1}`，且 `0≤t_j≤B`。特别要保留 `t_j=B`：此时正确结果是 `ŵ_j=0, c_(j+1)=1`。只根据未加进位的 a_j 判符号，或认为 t_j 永远小于 B，都会错。

逐位恒等式为

`a_j=ŵ_j+B c_(j+1)−c_j`。

乘 B^j 并作望远镜求和，对任意前缀长度 r 得

`Σ_(j<r) a_j B^j = Σ_(j<r) ŵ_j B^j + c_r B^r`。

取 r=L，并代入 A=z+εB^L，得到完整不变量

`z=Σ_(j<L) ŵ_j B^j+(c_L−ε)B^L`。  (KD.1)

因此末商是 `c_L−ε`，正确的末商零检查是

`c_L == int(z<0)`，

而不是无条件要求最后进位为零。负乘积通常需要最后进位 1。

### 恢复真实系数的证明

在第一位，真实 w_0 与 z 模 B 同余，且真实系数位于严格区间 `(-B/2,B/2)`，所以其平衡代表唯一。扫描输出在半开区间 `[-B/2,B/2)`，因此必等于 w_0；真值不可能落在唯一被排除的端点 −B/2。

假设前 r 位已恢复。移除它们并除 B^r，余数的最低位仍是真实 w_r，补码与 KD.1 的前缀关系使扫描当前的 `a_r+c_r` 与该余数模 B 一致。同样的唯一性给 `ŵ_r=w_r`。归纳至 L 后，全部系数恢复，真实多项式已无更高项，所以 KD.1 的末商必为零。

实现可额外拒绝 `ŵ_j=−B/2`，并检查最终 `c_L=ε`；这些是必要的故障检测，却不能替代第 1 节的先验界。若真正系数发生数位进位，解码器仍可能给出另一份范围合法的平衡展开。必须先证明原卷积系数不越半基，才可把恢复出的数位认作原卷积。

### 两个不执行的代数负值检查

当 z=−1、L≥2 时，所有补码 a_j=B−1。第一位给 ŵ_0=−1、进位 1；以后 t_j=B，给零数位并保持进位 1，末商为 1−1=0。

当 z=B−1、L≥2 时，a_0=B−1、a_1=0。恢复 ŵ_0=−1、ŵ_1=1，后续为零，最后进位 0 与正数 ε=0 相符。这说明最低补码位本身的符号不能代表整个 z 的符号。

## 4. 操作模型与实现检查点

下列伪代码只说明待审的解码算法，本轮没有作为科学核执行：

```python
blob = z.to_bytes(30 * L, "little", signed=True)
view = memoryview(blob)
carry = 0
for j in range(L):
    a = int.from_bytes(view[30*j:30*(j+1)], "little", signed=False)
    t = a + carry
    if t >= B // 2:
        w = t - B
        carry = 1
    else:
        w = t
        carry = 0
    if abs(w) >= B // 2:
        fail_closed()
    save_fixed_width_signed_coefficient(j, w)
if carry != int(z < 0):
    fail_closed()
```

这调用一次全宽 `to_bytes`，随后读取恰好 L 个固定 30-byte 切片；内循环只算固定宽整数。故扫描有 O(L) 次固定宽操作，导出及读取的总字节量 O(30L)。若数位宽 b 也视为变量，写成 O(bL) 的字节/位传输更准确。这里没有将大整数乘法成本也说成线性；只消除了逐位 `z >>= 240` 引起的剩余长整数反复复制。具体 Python 运行时的导出成本仍须随主运行记录，不能用这份操作计数冒充测速。

主实现可以对三个原始实乘积分别解码，或先在整数层形成 Gauss 的真实部/虚部再解码；后者仍须用最终 `2^235` 界，不得沿用只针对某一原始乘积的界而省略合并估计。无论采用哪一种，所有相消都在有符号整数中完成，原有三次一般实乘法及固定成本块不改变。

实际代码另须检查：30-byte 小端边界、输出顺序、零物理频率的索引 `(16,16,16)`、负零不存在、固定宽数位保存符号、全数组解析回读、原始输入和运行源码绑定。哈希定位字节，不能证明系数的代数值正确。

## 6. 有限模校验的边界

目前不采用模算法，但应防止把便宜校验写成确定性全复算。即使对全部输出验证了一个固定模数 q 下的相等，也只能推出系数差被 q 整除，不能推出整数差为零。

若未来对一组两两互素模数逐输出全部验证，且真输出和候选输出均已有 `|coefficient|<2^235` 的独立大小保证，那么差的绝对值小于 `2^236`。模数乘积大于 `2^236` 时，全部同余才足以确定性地推出每个整数差为零。只有一份模数列表或几个 residues 还不构成此证书；每份全输出模卷积及其算术也须被验证。本文不选素数、不实现 NTT，也不承诺其成本。

随机点值校验更不同：在素域 F_q 中，一个已知非零的差多项式若次数至多 35936，对均匀随机点误验为零的概率至多 `35936/q`。但若整份差多项式模 q 已经为零，此条件不成立，随机点必然无法发现整数错误。这个条件概率不能省略，随机检测也不能冒称前述直接整数全输出复算。
