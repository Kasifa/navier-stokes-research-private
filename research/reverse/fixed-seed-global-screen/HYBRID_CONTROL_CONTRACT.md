# 保留输运相消的后验控制：计算前的解析合同

纯热参照在已有A_-1全绝对值控制中无法到达终点小性门。下一步只检验一种更适合有限时间后验验证的控制：误差的L2能量保留完整无散输运相消；H2误差保留最高阶输运相消，并用显式Fourier常数控制剩余自作用。不逐次增加时间Taylor阶，不以数值正则图像代替误差证明。

设一个以后需要具体选定的v(t,x)为光滑、实值、无散、零均值的周期近似场，初始误差和完整残差R=v_t−νΔv−B(v,v)都有已知上界。这里v未生成，任何M_j或r_j都必须未来实际认证。B(f,g)=−P[(f·∇)g]保留完整周期Leray。误差w=u−v来自同一允许初值的真实NS。

统一使用归一化体积的L2，以及全Frobenius导数范数。记x=||w||2、z=||D²w||2、M_j=||D^jv||∞,F（j=1,2,3），r0=||R||2、r2=||D²R||2。待严格核验的候选预算为

x'≤M1 x+r0，
z'≤3M1 z+3M2 sqrt(xz)+M3 x+[441/(2ν)]z³+r2。

常数须从完整逐导数展开独立推出；若系数不对，先修正合同再使用。特别检查是否可由三维格点壳层求和自包含得到 A1(w)≤7||D³w||2、A_-1(w)≤6||D²w||2，及H1误差≤sqrt(xz)。处理零范数、supersolution比较和光滑延拓，不只写形式微分。不得让未认证真解导数进入系数。

若正的有限控制上解α,β覆盖x,z并满足终点 A_-1(v(T))+6β(T)<ν，则应由已有严格A_-1门认证同一原解全局。证明此接口不等于已提供可用v、已认证时间T、已控制空间尾或已通过终点门。
