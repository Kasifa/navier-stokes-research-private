# 单节点残差与指定控制函数族的接口

2026-09-08。PRIVATE_CORE。**现有节点证据排除 ε=2×10⁻⁷ 的指定残差包络；现有粗有理界不足以排除这个显式控制函数族的所有 ε。** 本文件只重排已有条件公式，没有选择第三个 ε、扫描、积分、新节点、指数求值实验或重复科学核。

本文件不是主 outcome。作者未撰写 PARAMETRIC_COST_LEMMA.md 及其两份审查；作者写过独立节点执行核，因此下面读取节点记录不算该核的又一次非作者审查。新节点精确对照的终审仍在进行，以下以当前存证给出的严格区间为输入，不替代其最终验收。

## 1. 三种要求须分开

固定 P.10 的参数

`T=5/2, μ1=μ2=19/5, μ3=6, A=2067/160, d=15/128`，

`L(t)=exp(A(1−e^(−t))−dt), f(t)=3/2−e^(−2t)/2`。

为简记令 H(t)=L(t)f(t)。只讨论同一族

`β_ε(t)=εH(t), α_ε(t)=β_ε(t)/64, ε>0`。

必须分别支付：同一参照实际残差/导数的全窗包络；该指定函数对所用控制右端的上解不等式；原后验定理的其余条件。一个 ε 在其中一项失败，不自动排除其它 ε，更不排除其它控制函数或同一 NS 解。

## 2. 节点给出的必要下界

设 t*=5/8，r_j 是原精确参照的完整节点残差范数。若全窗残差包络可用，则必有

`ε ≥ η := r2(t*) exp(5/4)`，

以及 `ε ≥ 64 r0(t*) exp(5/4)`。这是必要条件，满足它不证明其它时间点或全窗包络。

从已存 `full-nodal-independent-trial-01/result.json` 定义两个精确有理数：

`q_- = intervals["2"]["lower_times_exp_lower"]`，

`q_+ = intervals["2"]["upper_times_exp_upper"]`。

该记录先由原 r2 的范数下/上端，乘已验证的 exp(5/4) 有理下/上端，故

`q_- ≤ η ≤ q_+`。

记录中的严格拒绝是 `q_->1/5000000`，所以 ε=2×10⁻⁷ 不满足这个节点的 r2 要求。r0 记录在同一预算下为 NODE_PASS；其已证上端乘指数上端不超过1/320000000，乘64后不超过1/5000000。因此这个节点的两项必要预算由 r2 主导。该结论仍没有给出全窗残差上界。

## 3. P.3 是一组充分条件

既有 P.12 已证 A≥μ1、Ae^(−T)>d，因此 L≥1、H非减。P.3 对这一族的充分小性门恰为

`0<ε<ε_S := 1/[24 H(T)]`。  (NC.1)

它足以支付取满 P.1 包络的两条控制不等式；这并不说 ε≥ε_S 时该函数必然不是上解。只有实际全窗 M_j、r_j 同时被相应包络覆盖，并满足原终点等条件，才可引用原后验结论。

P.19 对 ε=2×10⁻⁷ 证明了这项条件充分性。新节点结果否定的是“现参照满足此 ε 的残差包络”，两件事没有逻辑冲突。

## 4. 取满包络时，指定函数的精确标量条件

代入 α=β/64，第一控制式乘64后的余量为

`[(A−μ1)e^(−t)+1−d]β+ε(L−1)e^(−2t)≥0`，

对所有 ε>0 都已由上述固定参数条件支付。第二个取满包络右端为

`F_env=(Ae^(−t)−1/2)β+(441/2)β³+εe^(−2t)`。

直接微分并除正 β 得 P.18 前的通式

`(β'−F_env)/β = 49/128 − (441/2)ε²H(t)² + g(t)`，

其中 `g(t)=(1−1/L(t))e^(−2t)/f(t)≥0`。所以固定时刻第二式成立当且仅当

`ε² ≤ K(t) := [2/(441 H(t)²)] [49/128+g(t)]`。  (NC.2)

在整个闭窗，它等价于 `ε²≤min_[0,T] K(t)`；K正且连续，最小值存在。本文没有定位该最小值，也没有通过积分或扫描求它。

尤其，成为全窗取满包络上解必须满足终点必要上界

`ε ≤ ε_N := [1/H(T)] sqrt{(2/441)[49/128+g(T)]}`。  (NC.3)

这个终点条件单独不是充分条件。由于 g≥0，有 ε_N≥ε_S；在T>0且L(T)>1时严格大于。可见不能把P.3失败等同于NC.2失败。

P.18已严格证明原 ε=3×10⁻⁷ 在终点失败。余量对 ε²严格递减，因此同一固定函数族中所有 ε≥3×10⁻⁷ 都不能为该取满包络提供上解。该判断仍不覆盖较小实际导数/残差右端，也没有排除全部正 ε。

## 5. 现有粗界究竟能排除多少

只用已审 P.14–P.16，而不新增指数计算：

`94770<L(T)<1079925/8, 431/288<f(T)<3/2`，

故

`H_-:=2269215/16 < H(T) < H_+:=3239775/16`。

定义由这些粗界导出的两个边界，而非新选择的预算：

`ε_G:=1/(24H_+)=2/9719325`，

`ε_H:=1/(24H_-)=2/6807645`。

则 `ε_G<ε_S<ε_H`。特别地，由H(T)<H_+，范围 `0<ε≤ε_G` 已可用旧粗界保证P.3。

对已经保存的有理端点，仅作整数交叉乘法，实际核得

`ε_G < q_- < q_+ < ε_H`。  (NC.4)

可复查的比较为：若q_-=n_-/d_-、q_+=n_+/d_+，则

`9719325 n_- > 2d_-`，`n_-d_+<n_+d_-`，`6807645 n_+<2d_+`。

另有 `5000000 n_->d_-`，对应原 ε=2×10⁻⁷ 的节点拒绝。这些比较只读已存整数并交叉相乘，没有重新算根号、指数或残差。

NC.4确实排除了“节点必要预算”与“现有粗界已保证的窗口 `(0,ε_G]`”相交。但**不能**据此说节点必要预算与准确P.3窗口 `(0,ε_S)` 不相交：实际 ε_S 仍位于跨过节点预算的粗区间 `(ε_G,ε_H)` 中。它也没有证明一定存在相交。

终点必要条件也不能由这些界完成排除。因为

`0≤g(T)<(1/144)/(431/288)=2/431`，

有

`ε_G<ε_N<U_N := [1/H_-]sqrt{(2/441)[49/128+2/431]}`。

而 `q_+<ε_H<U_N`。所以现有必要条件上界没有压到节点必要下界之下；要证明所有ε不可行，至少还缺能比较η与准确全窗门/终点门的更强证据。本文不补精度、不作新的界优化，更不把两个宽包围重叠写成可行性证明。
