## 2. 完整循环、半程和时间账

令接受节点 t_j=jT/m，j=0,…,m。初始化 U_0 为同一固定近似，G_0=W_0=0。驱动必须对 index=0,…,m−1 按顺序各调用一次已核 indexed_step，接受后才把完成步数增为 index+1；不把成本调用 index=m/2 当成已经走完前段。

index<m/2 的整步使用 phase=0，包含 index=m/2−1 那一步位于 a 的第四阶段。完成该步后先记录并保存接受的 U_{m/2}、G_{m/2} 和 W=0；其中 P_H2 U_{m/2} 完整保留。随后 index=m/2 的入口只清 W，U、G 和已有 H2 场全部保留。后半段每步 phase=1。G 自始至终从 0 累计，W 才是从 a 累计的第二历史。

步长先由原有理 T/m 准确组成，再一次转 binary64；每个 run 保存其有理数、float hex、`as_integer_ratio` 回读及正负／绝对转换误差。所有节点和 RK 阶段的数学时刻分别为 (j+c)T/m，其中 c∈{0,1/2,1}；phase 由整数 index 决定，不由浮点时刻比较决定。

每个接受节点的记录含 j、准确 jT/m、其一次转换的 hex／回读误差。另保存相对于准确节点的有理偏移 j·Fraction(h_float)−jT/m；若还报告浮点 j*h_float，则其回读误差亦分开。禁止把反复浮点累加的时刻冒充准确节点，禁止最后一步偷偷改步长去“纠正”终点。这些记录明确区分目标有理 T 与浮点步长实际使用的热因子，并不消除时间误差。

## 3. 每步观测与数值完整性

对每个接受节点，包括 j=0，记录 H0、H1、H2、G、W 的 A0，另记录

    e1_j=P_H1 U_j−G_j，
    F1_j=||e1_j||A0−||G_j||A0/4。

对 j≥m/2，再记录

    e2_j=P_H2 U_j−W_j，
    F2_j=||e2_j||A0−||W_j||A0/4。

在 a 前，F2 字段为 null 并注明第二积分尚未开始，不用 W=0 制造原合同第二门的“失败”数据。a 处及后续 F2 是过程诊断，原第二门只在 j=m 支付；第一门要求全部 j≥m/2 的样本，而不是只看终点。e1/e2 必须先作完整复向量差再取 Hermitian A0，不能用两个范数之差代替余项范数。

每条记录列数值来源／目标是否有限、是否为非零浮点向量，以及 F≤0 的离散标志。来源零时不作比值；0≤0 不能满足另列的非零要求。所有这些标志都标为浮点采样记录，不能直接称真实门通过、严格正下界或非零认证。不得因途中 F 为正或负而缩窗、换 m、换环带、提前停止有不利样本的完整观测，或仅保存有利模式。

完整 U 每步记录有限性、均值、共轭、横向、C3 缺陷、归一化能量、黏性耗散、A0、保留域外残留及立方体边界占据；G/W 同样记录有限性、共轭、横向与 C3 缺陷，按各自紧凑频率映射计算。保留原始缺陷及尺度：共轭／C3 分母为 max(1,最大系数模)，横向再乘 max(1,最大频率模)。不对非 C3 数据另作投影以掩盖误差。

任一非有限状态或源、缺失阶段、索引错位、来源／输入／源码绑定变化、文件完整性或资源失败，保留失败并停止该 run。有限的结构缺陷本草案只记录原值与最大值，不把旧单步 2e−12 验收阈值自动当成全轨迹误差界，也不靠事后调容差取得通过。拟采用的 driver 若要加告警或硬失败阈值，必须在最终合同先锁，不能由输出决定。

每步统计小型 JSONL 并刷新；每个完整步更新累计时间、已完成步数、下一 index、phase、最近检查点和基于已完成步的 ETA。ETA 只是运行信息，不驱动步长或科学参数。能量变化加指定耗散求积可作为离散账记录，不能硬改状态让它恒等成立。

## 4. 完整来源、历史和原解残差

对原解 u，z_i=u−P_Hi u；真实两个余来源完整为

    e1(r)=e^{rΔ}h1(0)
      +∫₀ʳ e^{(r−q)Δ}P_H1[B(h0,z0)+B(z0,h0)+B(z0,z0)](q)dq，
    e2(T)=e^{(T−a)Δ}h2(a)
      +∫ₐᵀ e^{(T−r)Δ}P_H2[B(h1,z1)+B(z1,h1)+B(z1,z1)](r)dr。

h1(0)=0 不清除前式三项；h2(a) 未知且不得置零。两式包含初始种子、非相邻频率、外场交叉和回流。压力在完整 Leray 中，黏性在原热半群中。

对于以后若构造的光滑有限谱时间重建 V、G_rec、W_rec，必须区别

    D_U=∂t V−ΔV−P_K B(V,V)，
    R_NS=∂t V−ΔV−B(V,V)=D_U−(I−P_K)B(V,V)，
    D_G=∂t G_rec−ΔG_rec−P_H1 B(P_H0 V,P_H0 V)，
    D_W=∂t W_rec−ΔW_rec−P_H2 B(P_H1 V,P_H1 V)， r>a。

支持外全部非线性漏出是 R_NS 的一部分，不能只检查保留域残差。重建的两个余项方程除上述交叉结构外，还分别含 P_H1 D_U−D_G、P_H2 D_U−D_W，以及初端／a 端误差。仅有逐步数组和 RK 更新代数一致性，尚未构造这种光滑重建或严格估计这些残差；不得把“代码按公式更新”说成 R_NS、D_G、D_W 为零。

OBSERVATION_ERROR 的 OE.1 要求完整 [0,T] 的真实存在和齐次未归一化 H³ 轨迹误差 R(r)；Fourier 归一化须转为 ρ=(2π)^(−3/2)R。其门误差为状态误差加 5/4 倍历史误差，实际读取、历史求积、向量相减和范数求值还需另付 η。四份采样对照都没有自动支付这些输入。

每个 run 采用新独占目录，不覆盖旧输出。保存 j=0 和每个完成步数 j=32,64,…,m 的完整无损检查点；m=256 共 9 份，m=512 共 17 份。a 和 T 已包含其中，结果文件以对应路径与 SHA 引用它们，不再重复写一份大数组。每步只写标量统计，不把约 100–200 MB 的完整速度每步落盘。

每份检查点包含完整 U、紧凑 G/W、N/K/m、完成步数与 next_index、下一阶段及半程重置是否待执行、准确 T/a/h 与 float 规范、输入／源码锁绑定、累计计数／诊断记录位置。格式、分量轴、FFT 正负频率顺序和紧凑环带排序必须明确。先写唯一临时文件，完成关闭与 SHA 后在同一目录原子改名为该 j 的唯一正式名；保留此前检查点。不能把一半阶段标为可恢复端点。

这些状态足够按同一源码继续下一整步，但本草案**不授权自动恢复或重跑**。故障后仅保留已完成检查点及失败产物，根另审恢复范围、剩余预算和新增 worker 调用计数，不能把第二次调用藏成原一次执行。

不保存额外重复 H0/H1/H2 大数组，因为它们可由同一 U 精确投影重建。只计三个 complex128 向量块时，单检查点原数组字节粗上界为

这是按数据布局手计的存储预算，未枚举环带或运行科学程序。给元数据／容器头留余量后，建议每份检查点的文件预算：N128 为 128 MiB，N160 为 224 MiB；驱动必须实际记录每份大小，不能把估计当实测。其余全部 JSONL／索引／回执合计预留 64 MiB。下表的 run 输出上界还留有失败时一个额外完整状态及临时产物余量。

## 7. 固定比较与可声称的最高范围

同一空间下比较 256 与 512 步在共同准确节点 jT/256：细网格取 2j，不插值制造同刻；同一步数下比较两种空间。每步小型统计允许全共同节点比较；完整向量比较仅在确实保存的共同检查点、a 和 T 进行。不能声称未保存的逐步完整数组已经比较。跨空间先按同一 signed 频率嵌入／限制到共同立方体，较大域的额外部分单列，不能悄悄删除后只报一致。

空间差、时间差、截断边占据和结构缺陷分别报告，不以某一对相近替四路全部比较，也不事后只选有利一路。任何数值比较执行及其标量定义须在最终 driver 或独立后处理合同先锁；本草案不开始这些计算。

实现完成、有限状态、资源通过和浮点采样门是不同字段。完成四条有限 Galerkin 轨迹最多给同一初值近似的固定观测记录与对照，尚不是同一真实 NS 解的全窗门：第一门覆盖 [a,T] 每一时刻，第二门及非零要求在 T，不能用有限观察网格代替。没有 OE.1、完整历史求积及评估误差时，不将离散 F 的号升级为严格通过／否定，亦不推出一般不可能、形状返回或无限迭代。
