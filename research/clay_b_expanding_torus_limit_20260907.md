# 零年龄序列：把初值、压力和奇点一起带到全空间

## 1. 本稿的准确目标

设 \(L_n\to\infty\)，\((U_n,P_n)\) 是 \(\mathbb T_{L_n}^3\) 上无外力、单位黏性的全局suitable Leray解，初值 \(f_n\) 无散、平均零，且
\[
 \sup_n\|f_n\|_{\dot H^{1/2}(\mathbb T_{L_n}^3)}\le M<\infty.
 \tag{MQ.1}
\]
积分不除以胞体积，压力取周期零均值规范。假设每项在同一固定时空点 \(z_*=(0_{\mathbb R^3},1)\) 奇异；MI零年龄分支经首次奇点缩放即为这种序列。证明目标是提取 \(f\in\dot H^{1/2}(\mathbb R^3)\)、全空间局部能量解U及压力q，使
\[
 \|f\|_{\dot H^{1/2}(\mathbb R^3)}
 \le\liminf_n\|f_n\|_{\dot H^{1/2}(\mathbb T_{L_n}^3)},\qquad
 0<T_{\rm mild}(f)\le1.
 \tag{MQ.2}
\]
特别地f非零。这一非零性要在最后经解类别、奇点传递与弱强一致性取得，不能从初始弱紧性直接宣布。

沿用MI所列周期解存在、初迹、局部能量和光滑延拓接口；MP.1–10已给一致局部估计。全空间临界mild理论采用 \(C_t\dot H^{1/2}\cap L^4_t\dot H^1\) 的标准类及正时间平滑，参见[Rusin–Šverák §3](https://arxiv.org/html/0911.0500v1)。后文分别注明奇点稳定性与弱强定理的原著接口，并逐项检验本序列的适用条件。本稿不重证这些外部定理的全部依赖。

## 2. 变周期初值的紧性：不使用胞内零延拓

取居中胞 \(C_L=[-L/2,L/2)^3\)、实际波数 \(\xi_k=2\pi k/L\)，\(\widehat h(k)=L^{-3}\int_{C_L}h(x)e^{-i\xi_k\cdot x}dx\)。周期提升的准确公式为
\[
 \|h\|_{\dot H^{1/2}(\mathbb T_L^3)}^2
 =L^3\sum_k|\xi_k||\widehat h(k)|^2
 =\frac1{2\pi^2}\int_{C_L}\int_{\mathbb R^3}
 \frac{|h(x)-h(y)|^2}{|x-y|^4}\,dy\,dx.
 \tag{MQ.3}
\]
证明：对 \(z=y-x\) 固定，胞内Parseval给差分平方积分为 \(2L^3\sum_k(1-\cos(\xi_k\cdot z))|\widehat h(k)|^2\)。Tonelli及 \(\int_{\mathbb R^3}(1-\cos(\xi\cdot z))|z|^{-4}dz=\pi^2|\xi|\) 给式。后一个积分可旋转后先积横向两变量，得到 \(\pi\int_{\mathbb R}(1-\cos(|\xi|s))s^{-2}ds=\pi^2|\xi|\)。由稠密性延至整个齐次空间；零模两边均为零。

先取子列使范数收敛于原序列下极限 \(m_*\)。周期Sobolev给胞内 \(L^3\) 范数至多CM。每个固定 \(B_R\) 最终包含于 \(C_{L_n}\)；限制MQ.3的两个积分变量到该球，连同 \(\|f_n\|_{L^2(B_R)}^2\le C R M^2\)，得到一致局部 \(H^{1/2}\) 界。Rellich、空间对角提取及进一步子列给
\[
 f_n\to f\quad\hbox{于 }L^2_{\rm loc}(\mathbb R^3)\hbox{ 并几乎处处},
 \qquad \operatorname{div}f=0.
 \tag{MQ.4}
\]
对固定球的 \(L^3\) 积分用Fatou，再令球扩张，得 \(f\in L^3(\mathbb R^3)\)、\(\|f\|_3\le CM\)。对双球积分也用Fatou及单调收敛，得全空间MQ.3同型积分至多 \(m_*^2\)。全空间Gagliardo表征及L3消除齐次常数歧义，于是 \(f\in\dot H^{1/2}\)、\(\|f\|_{\dot H^{1/2}}\le m_*\)。没有把周期提升当成全空间L3函数，也没有声称胞内零延拓有一致H1/2范数。此时f仍可能为零。

## 3. 同一压力规范与含初端的速度紧性

固定 \(R_*\ge1\)，足够大使MP时间窗覆盖 \((0,2)\)。对所有足够大n，MP给
\[
 \mathop{\rm ess\,sup}_{0<t<2}\sup_x\int_{B_{R_*}(x)}|U_n(t)|^2\le K_*<\infty,
 \qquad \sup_x\int_0^2\int_{B_{R_*}(x)}|\nabla U_n|^2\le K_*.
 \tag{MQ.5}
\]
这里R_*和K_*只依赖M。任意更大的固定观察球使用有限覆盖，故有相应一致局部能量界，仍保留对球中心的一致性。先固定尺度再取n，不能要求某个有限n容纳全部尺度。

定义 \(q_n=P_n-(P_n)_{B_1(0)}\)。对每个固定球，取覆盖它及B1的MP截断球；若MP规范后压力为 \(a_n=P_n-c_n(t)\)，则 \(q_n=a_n-(a_n)_{B_1}\)。Jensen给每个固定球上的一致 \(L^{3/2}\) 界。更具体地，MP.6、MP.8及能量界给，对 \(0<t<2\)，
\[
 \int_0^t\int_{B_R}(|U_n|^3+|q_n|^{3/2}+|q_nU_n|)
 \le C_R(t^{1/4}+t).
 \tag{MQ.6}
\]
压力通量项用空间时间Hölder；各常数可依赖固定R、M，不依赖n。这保留了靠近时间零的一致通量小量。

完整方程给 \(\partial_tU_n\) 在每个固定球的 \(L^{3/2}(0,2;H^{-3})\) 中有界：梯度项由L2控制，二次项由局部能量控制，压力项由刚得到的L3/2控制。Aubin–Lions先得强局部 \(L^2_{x,t}\)，与能量类的L10/3界插值得
\[
 U_n\to U\text{ 于 }L^3(B_R\times(0,2)),\qquad
 q_n\rightharpoonup q\text{ 于 }L^{3/2}(B_R\times(0,2))
 \tag{MQ.7}
\]
对所有固定R成立，使用一次对角子列。没有先删掉 \((0,\delta)\)。时间导数的测试配对及局部L2稠密性给相容代表 \(U\in C_w([0,2);L^2_{\rm loc})\)、\(U(0)=f\)；测试是任意紧支撑L2向量场，不限无散场。能量下半连续和中心的可数稠密逼近使MQ.5对U仍成立。

## 4. 强压力与完整全空间近远表示

令 \(K=\partial_i\partial_j(4\pi|x|)^{-1}\)，取分布意义的双Riesz核，保留接触项。固定观察 \(B_R\)，取 \(S\ge4\max(R,R_*,1)\)，令 \(\chi_S=1\) 于B4S、支集在B8S。固定S后，MP.3使
\[
 \Pi_{n,S}:=K_{L_n,ij}*(\chi_SU_{n,i}U_{n,j})
 \longrightarrow \Pi_S:=K_{ij}*(\chi_SU_iU_j)
 \quad\hbox{强于 }L^{3/2}((B_R\cup B_1)\times(0,2)).
 \tag{MQ.8}
\]
欧氏CZ处理主项，强L3速度控制二次项；光滑余核为 \(O(L_n^{-3})\)，乘固定B8S内一致L2质量后趋零。周期零模的余项保留至此才取极限。

设剩余周期远压力为 \(F_{n,S}=P_n-\Pi_{n,S}\)。对 \(x\in B_R,z\in B_1\)，以R_*球覆盖距离 \(2^kS\) 的全胞壳，MP.3给
\[
 |F_{n,S}(x,t)-F_{n,S}(z,t)|
 \le C(R+1)\frac{K_*}{R_*^3}\sum_{k\ge0}(2^kS)^{-1}
 \le \frac{C_R}{S}.
 \tag{MQ.9}
\]
最远胞壳仍在求和中；只需 \(L_n\) 对这个固定S足够大。因而 \(q_n\) 与 \(\Pi_{n,S}-(\Pi_{n,S})_{B_1}\) 的差在B_R上一致为 \(O_R(S^{-1})\)。先令n趋无穷，再令S趋无穷，得到 \(q_n\to q\) 强于每个 \(L^{3/2}(B_R\times(0,2))\)。这是通过尾部估计证明的强压力，不是对一般局部弱解序列的额外假设。

还须获得解类别要求的精确公式，而不止局部Poisson方程。固定任意中心x0与r>0，取 \(\theta=\mathbf1_{B_{4r}(x_0)}\)。周期压力同样精确分成 \(K_{L_n}*(\theta U_n\otimes U_n)\)、外部核差及一个时间函数。近场由MQ.8同理传递。远部先截到固定大球，用核的局部收敛与 \(U_n\otimes U_n\) 强收敛；再用MQ.9类型的尾界撤掉截断。因此，在 \(B_{2r}(x_0)\times(0,2)\) 上，
\[
 q=K_{ij}*(\theta U_iU_j)
 +\int_{\mathbb R^3}\![K_{ij}(x-y)-K_{ij}(x_0-y)](1-\theta(y))U_i(y,t)U_j(y,t)dy
 +c_{x_0,r}(t).
 \tag{MQ.10}
\]
外部积分绝对收敛。小于固定尾截断的部分由局部能量控制；无穷远由MQ.5球覆盖及四次衰减控制。周期公式两侧之差在空间恒定，强L3/2极限仍如此；取该差的球平均得到 \(c_{x_0,r}\in L^{3/2}(0,2)\)。指标式求和、卷积、核符号与MP一致；BT原著把核定义为本稿K的负号，相应整体负号换算后公式相同。这里没有假设光滑截断与原著特征函数定义自动等价，而是对特征函数另作同样的近远传递。

## 5. 初始迹与局部能量解类别

对含时间零初始项、支集在 \(\mathbb R^3\times[0,2)\) 的局部能量测试传极限：初始项由MQ.4，速度与压力通量由强收敛（其实压力弱、速度强已足够），耗散由下半连续性处理。对 \(0\le\phi\in C_c^\infty\)，MQ.6给几乎处处t的上界
\[
 \int\phi|U(t)|^2\le\int\phi|f|^2+C_\phi(t^{1/4}+t).
 \tag{MQ.11}
\]
用第3节的弱连续代表，从这些良好时刻逼近任意t<2，弱下半连续把上界扩展到所有t。令t下降到零，弱初迹与加权范数上极限界合用，得到 \(U(t)\to f\) 强于L2_loc。这里没有把几乎处处时间结论直接改成所有时间，也不在t=2端点宣称额外迹。

至此，完整分布方程、对空间中心一致的局部能量/耗散、MQ.10的全空间压力表示、强局部初迹、局部能量不等式以及全部紧支撑L2测试的弱连续性均已核对。因此U属于[Bradshaw–Tsai Definition 1.1](https://arxiv.org/html/1907.00256v1)在时间区间 \([0,2)\) 的 \(\mathcal N(f)\)。这是局部能量解类别，不是全空间有限总能量的Leray–Hopf类别，也未构造本极限在t≥2的延拓。

## 6. 保留奇点，然后才比较mild解

在 \((0,1)\) 附近取固定内部时空柱。MQ.5、MQ.7及局部压力界满足[Rusin–Šverák Proposition 2.2、Lemma 2.1](https://arxiv.org/html/0911.0500v1)的奇点稳定性条件，故U在该点奇异。其机制使用强L3速度、近场CZ压力与远部调和压力的振荡衰减；不能把仅有速度弱收敛当作该定理。根任务已直接重读Proposition 2.2陈述与Lemma 2.1证明，MP与本稿的强压力提供了更强的输入。

取任意 \(0<T<\min(T_{\rm mild}(f),2)\)，令v为从f出发的临界mild解。其mild恒等式配合 \(p_v=R_iR_j(v_iv_j)\) 恢复完整NS分布方程。逐项验证同一 \(\mathcal N(f)\) 类：\(v\in C([0,T];L^3)\) 给强局部初迹、全部紧支撑L2测试连续性，以及 \(\sup_{t,x}\int_{B_r(x)}|v|^2\le Cr\sup_t\|v(t)\|_3^2\)；\(v\in L^4_t\dot H^1\) 给有限时间的局部L2耗散。压力 \(p_v\in C_tL^{3/2}\)；分割其全空间卷积即得MQ.10同型公式，因为远核 \(|y|^{-3}\) 在球外属于L3，时间规范由 \(C_r\sup_t\|v(t)\|_3^2\) 控制。正时间平滑给内部柱上的局部能量等式。故v也属于同一有限时间的 \(\mathcal N(f)\)。

最后，L3在L2_uloc中的光滑紧支撑逼近给 \(f\in E^2\)；Hölder和 \(|g|^3\) 积分绝对连续性给
\[
 \|g\|_{m^{2,1}}\le C\|g\|_3,\qquad
 \lim_{r\downarrow0}\sup_x r^{-1}\int_{B_r(x)}|g|^2=0\quad(g\in L^3).
 \tag{MQ.12}
\]
所以 \(v\in C_t m_0^{2,1}\subset C_t m_\epsilon^{2,1}\)，可固定任意足够小的正ε，毋须假设v的整个临界范数很小。[Bradshaw–Tsai Theorem 1.9](https://arxiv.org/html/1907.00256v1)给U=v于这个区间。根任务直接读其Theorem 1.7/1.9陈述及§4相应完整证明；把它作为明确的已有文献接口使用，未重证其Theorem 1.2等全部外部依赖。

若 \(T_{\rm mild}(f)>1\)，可取 \(1<T<\min(T_{\rm mild}(f),2)\)，与U在内部点 \((0,1)\) 奇异而v光滑矛盾。于是 \(T_{\rm mild}(f)\le1\)。临界局部理论给其严格为正；若f=0，小数据全局解和刚才的弱强一致性再次矛盾。结合第2节得MQ.2。证明结束。
